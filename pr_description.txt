🧪 Add missing tests for CanceladoState

🎯 **What:** The testing gap addressed
This PR adds unit tests for `CanceladoState` to ensure it correctly throws an `InvalidOperationException` when attempting to advance or cancel the service order state, and correctly returns its status name.

📊 **Coverage:** What scenarios are now tested
- Calling `AvancarStatus()` on an `OrdemServico` in `CanceladoState` throws an exception.
- Calling `CancelarOS("motivo")` on an `OrdemServico` in `CanceladoState` throws an exception.
- Calling `ObterStatusNome()` of `CanceladoState` returns "Cancelado".

✨ **Result:** The improvement in test coverage
The code coverage for `CanceladoState` is now complete. The state class is now resilient against regressions.
