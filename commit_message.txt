🔒 [Security Fix] Remove hardcoded demo password

🎯 **What:** Removed hardcoded demo password from Program.cs.
⚠️ **Risk:** Hardcoding credentials exposes sensitive access to anyone with access to the source code, posing a severe security risk. Even though it's a demo account, it should follow secure configuration practices.
🛡️ **Solution:** Updated `Program.cs` to read the demo credentials from configuration (e.g. `appsettings.json` or Environment Variables). Added a `DemoCredentials` section in `appsettings.json` and updated `README.md` to document the new secure setup.
