🎯 **What:**
Refactored the `Index` method in `Controllers/AdminController.cs` by extracting the code that populates the `ViewBag` into two new helper methods: `PopulateDashboardViewBag` and `PopulateErrorViewBag`.

💡 **Why:**
The `Index` method was becoming too large and doing multiple things. Extracting the ViewBag population logic into helper methods improves readability, makes the main controller action more concise, and adheres to the Single Responsibility Principle. This makes the codebase easier to maintain.

✅ **Verification:**
* Verified the modifications using `git diff`.
* Successfully compiled the project using `dotnet build`.
* Ran the full test suite using `dotnet test` and specifically `AdminControllerTests`, confirming all tests passed without regressions.

✨ **Result:**
The `Index` method in `AdminController.cs` is now much smaller and easier to read. The logic for populating dashboard data and error messages is neatly encapsulated in dedicated helper methods, improving overall code health without changing the existing functionality.
