🔒 [security fix] Fix Open Redirect in EquipamentoBackupController

🎯 **What:** The vulnerability fixed
The `EquipamentoBackupController.Devolver` method used the `Referer` header from incoming requests and passed it directly to the `Redirect()` method without validation.

⚠️ **Risk:** The potential impact if left unfixed
This allowed an Open Redirect vulnerability where attackers could trick users into clicking a legitimate-looking link pointing to the application, which then redirects them to a malicious site. This can be used for phishing attacks, credential theft, or malware distribution.

🛡️ **Solution:** How the fix addresses the vulnerability
The solution uses `Url.IsLocalUrl(referer)` to validate that the redirect URL is a local path within the application before calling `Redirect()`. This prevents the application from redirecting to external or untrusted domains. We also updated the unit tests to correctly mock the `IUrlHelper` interface with `IsLocalUrl`.
