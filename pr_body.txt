🎯 **What**
Extracted the XML element creation logic for `<Servico>`, `<Prestador>`, and `<Tomador>` inside `GerarXml` of `NfseXmlGeneratorService` into separate private helper methods (`GerarServico`, `GerarPrestador`, `GerarTomador`). Also moved the `XNamespace ns` variable to a static readonly class field `_ns`.

💡 **Why**
This improves the readability, maintainability, and testability of the `NfseXmlGeneratorService.cs` class. The main `GerarXml` method was previously very long and monolithic. Breaking it down into smaller, focused helper methods reduces cognitive load and makes the XML structure easier to reason about and modify in the future. Moving the namespace to a class field reduces repetition.

✅ **Verification**
- Checked `git diff` to ensure the exact logic of the XML nodes was preserved untouched during the extraction.
- Ran the full test suite (`dotnet test`), verifying that all 292 existing tests pass, particularly the ones in `NfseXmlGeneratorServiceTests`.

✨ **Result**
The `GerarXml` method is now significantly shorter and focuses on the higher-level structure of the NFS-e document, delegating the detailed element construction to well-named helper methods. No external behaviors or output formatting were changed.
