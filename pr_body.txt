🎯 **What:**
Added `.AsNoTracking()` to the database query in `FaturamentosController.GerarReciboPagamento`.

💡 **Why:**
The `GerarReciboPagamento` endpoint retrieves a `Faturamento` entity with related `OrdemServico` and `Cliente` data simply to generate a PDF receipt. These entities are not modified, so EF Core's change tracker does not need to snapshot or track them.

📊 **Measured Improvement:**
Since this change avoids object tracker allocation inside the framework, traditional macro-level latency metrics in a black-box test might not show a substantial difference for a single query. However, adding `.AsNoTracking()` is a proven EF Core best practice for read-only queries. It eliminates the memory and CPU overhead of setting up tracking snapshots for the graph (`Faturamento` -> `OrdemServico` -> `Cliente`), reducing GC pressure and increasing throughput under load.
